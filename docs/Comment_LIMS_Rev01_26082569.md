1.  หน้า "การจัดการตัวอย่าง"

    1.  Function -- ทะเบียนตัวอย่าง

        1.  สามารถ Filter ด้วยการ scan , ค้นหาชื่อเครื่อง, ผู้ดูแล

    2.  Function - หน้า Popup เพิ่มรายการใหม่

        1.  เพิ่ม Tab สำหรับ กรอก Barcode ID หรือ Gen Barcode ID และ สามารถ
            Print สติ๊กเกอร์ได้

        2.  ผู้ดูแลเป็น Dropdown

        3.  เพิ่ม Description เพื่อลงรายละเอียดอื่นๆ

    3.  Function - ย้ายตำแหน่ง

        1.  สามารถสแกนได้ เช่น Scan ตู้

2.  การจัดการเครื่องมือ

    1.  Function - เพิ่มเครื่องมือ

        1.  เพิ่ม S/N

        2.  เพิ่ม ประเภท

        3.  เพิ่ม ผู้ผลิต

        4.  เพิ่ม รุ่น

        5.  เพิ่ม Location

        6.  เพิ่ม Installation Date

        7.  เพิ่ม Vendor

        8.  เพิ่ม Vendor Contact Detail

        9.  สามารถเพิ่มเอกสาร (บัตรรับประกัน)

    2.  Function - เพิ่มผลการ Calibrate (หน้าใหม่)

        1.  เพิ่ม Search Bar

        2.  เพิ่ม S/N

        3.  เพิ่ม วัน Calibrate (Calibration Date)

        4.  เพิ่ม รูปแบบการ Calibrate (Calibration Type)

        5.  เพิ่ม ค่าวัดจากการ Calibrate (Calibrate Value)

        6.  เพิ่ม ค่ายอมรับของการ Calibrate (Acceptance Value)

        7.  เพิ่ม ผลการ Calibrate (Result (Pass/Fail))

        8.  Due Date หรือ วันที่กำหนดรอบถัดไป ออกแบบใหม่หน่อยว่า
            จะทำไงให้มันสามารถกำหนดได้มากกว่า 1 Due Date

        9.  สามารถเพิ่มเอกสาร (Certificate)

3.  การจัดการสินค้าคงคลัง

    1.  Function -- เพิ่มรายการ

        1.  เพิ่ม ผู้ดูแล

        2.  เพิ่ม Manufacturer

        3.  เพิ่ม Location

        4.  เพิ่ม Vendor

        5.  เพิ่ม Vendor Contact Detail

    2.  Function -- รับของเข้าคลัง (หน้าใหม่)

        1.  เพิ่ม Search หารายการ

        2.  เพิ่ม Lot No.

        3.  เพิ่ม Expire Date

        4.  เพิ่ม QTY
